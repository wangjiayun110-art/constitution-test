# 体质自测 · 中医九种体质

基于中华中医药学会《中医体质分类与判定》(ZYYXH/T157-2009) 标准的中医体质自测网站。

## ✨ 功能

- **45 题科学自测**：覆盖九种体质核心表现
- **转化分计算**：标准公式 `(原始分-条目数)/(条目数×4)×100` 判定体质类型
- **雷达图可视化**：直观展示九种体质分布
- **个性化调养建议**：饮食 / 起居 / 运动 / 情志四维度
- **历史记录**：localStorage 本地保存，趋势折线图追踪变化
- **报告导出**：一键导出 PDF + 结果分享

## 🛠 技术栈

- 原生 HTML / CSS / JavaScript（无构建依赖，双击即用）
- Chart.js 4.x — 图表渲染
- html2canvas + jsPDF — 报告导出
- localStorage — 历史记录存储

## 🚀 使用

**方式一：直接打开**

双击 `index.html` 即可在浏览器中使用。

**方式二：本地服务器**

```bash
python -m http.server 8000
```

访问 http://localhost:8000
